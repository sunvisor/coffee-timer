コーヒータイマーアプリ
======

コーヒーを淹れるときのタイマーになるアプリ

- レシピに従って、コーヒーを淹れる手順を案内する Web アプリケーション
- Vite / React でローカルでのみ動く。サーバーサイドはなし
- 最終的に Cloudflare にデプロイする
- app ディレクトリに Vite プロジェクトがある
- 記述言語は TypeScript + React Compiler
- レシピを (複数) 登録できる、レシピは localStorage に保存する
- 抽出を実行する時には、時間・量を表示させつつ、タスクごとに終了時間に、音を鳴らす
- 説明文は Markdown が利用可能。改行は改行とみなす

- 量 (g): 抽出タスクの場合のみ

画面
----

### ホーム画面

- レシピ の一覧を表示
- レシピを選択すると抽出画面に遷移
- ＋ ボタンをヘッダ右上に表示、タップするとレシピ追加画面に遷移
- ⚙️ボタンで設定画面へ

### 抽出画面

- レシピの各項目と「抽出開始」ボタンを表示
- 抽出開始ボタン をタップしたらタスク1 の画面に遷移

#### タスク画面

- タスクの種別・説明・時間・量を表示
- 時間をカウントダウン
- 抽出タスクの場合は
    - 量を0からカウントアップ (時間内に指定の量を淹れるため)
- タスクの終わり時間になったら次のタスクへ 
- 最後のタスクを終わったら終了画面を表示

#### 終了画面

- お疲れ様でした。美味しいコーヒーをどうぞ

### レシピ追加画面

- レシピの各項目を入力できる
- タスクの一覧を表示
- タスクの追加ボタンでタスクを追加
- タスクの順番を変更できる
- 保存ボタンで保存する

### 設定画面

- レシピの保存: レシピデータを json ファイルでダウンロードする
- レシピの読み込み: json ファイルを読み込む
